# Agents Amp raster asset provenance

The selected shell and button atlases were created with the built-in Codex
`imagegen` workflow on 2026-08-26 for this repository. Variant A was approved
for runtime use.

## Input roles

- The existing 680×520 Agents Amp popup was the strict layout and actor-clearance
  reference.
- The earlier empty 1360×1040 shell was a geometry reference.
- A classic late-1990s media-player screenshot was a style reference only for
  navy/graphite color, steel bevel contrast, fine pixel dithering, yellow guide
  rails, and black LCD contrast.
- No reference image was copied or shipped as a runtime asset.

## Selected shell prompt

Create an original, textless 1360×1040 HiDPI raster chrome shell for an exact
680×520 desktop popup. Preserve three stacked modules with 2× geometry:
player `y=0 h=320`, an 8 px gap, equalizer `y=328 h=276`, an 8 px gap, and
playlist `y=612 h=428`. Use dark midnight-navy and graphite faceplates, fine
ordered pixel dithering, cool-steel double bevels, pale one-pixel highlights,
small screws, black recessed apertures, and paired warm-yellow title rails.

Preserve the live layout: a left indicator rail; a large divided player LCD;
two EQ/PL wells and a volume channel; exactly eight transport wells; a large
left spectrum aperture; exactly ten decorative vertical sliders; a separate
two-row reset aperture; a large playlist/table aperture with scrollbar channel;
and exactly four bottom action wells with width ratio `140:124:210:162`.

Leave every live-data aperture solid black and unobstructed. Do not render text,
numbers, labels, pseudo-text, music data, charts, progress bars, active LEDs, or
equalizer segments. Do not include a third-party name or logo, lightning symbol,
character, mascot, copied skin graphic, trademark, watermark, perspective,
purple neon, smooth modern gradient, or rounded app-card styling.

## Button prompts

Generate exactly four empty rectangular beveled button sprites in one horizontal
row on a genuinely transparent background. Match the selected shell's navy,
graphite, cool-steel and pale-silver pixel-metal treatment. Keep the centers
empty for live labels and icons. Create an idle atlas with raised top/left
highlights, then edit only the bevel lighting to create a pressed atlas with the
center visually recessed by about two pixels. Do not add text, icons, symbols,
branding, surrounding panels, shadows outside the sprites, or extra buttons.

The generated checkerboard preview was converted to real alpha without changing
the button pixels. Runtime crops use these 2× sizes:

- refresh: 280×62
- profile: 248×62
- settings: 420×62
- close: 324×62
